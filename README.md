1.Python 
The core programming language used to perform data analysis, data manipulation, and visualization.
2.Pandas 
Used to load, clean, and structure the dataset.
Helps in identifying and imputing or removing missing values.
Performs data aggregation , filtering, and datetime conversion
3.Matplotlib 
Provides fundamental plotting capabilities for creating basic visualizations such as Line Charts, Bar Charts, Pie Charts, Histograms, and Box Plots.
4.Seaborn 
Used for loading the built-in taxis dataset.
Provides high-level interfaces for creating statistical plots such as Count Plots, Scatter Plots, Heatmaps, Pair Plots, and Violin Plots.
5.Jupyter Notebook 
The environment used to write code interactive cell-by-cell and immediately view the generated visualizations and data outputs.
